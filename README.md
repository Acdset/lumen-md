# Lumen

面向 macOS 的现代化 Markdown 编辑器，灵感来自 [Typora](https://typora.io/)：实时预览、无干扰写作、文件树与大纲。

## 功能

- 实时预览 / 源码双模式（`⌘/`）
- 文件树、大纲、字数统计
- 专注模式、打字机模式
- 纸白 / 夜墨 / 羊皮主题
- 打开 / 保存 Markdown，导出 HTML
- KaTeX 公式、代码高亮、任务列表

## 开发

```bash
npm install
npm run dev
```

## 打包

```bash
npm run dist
```

产物在 `release/` 目录。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建 | ⌘N |
| 打开 | ⌘O |
| 保存 | ⌘S |
| 切换源码 | ⌘/ |
| 侧边栏 | ⌘\\ |
| 大纲 | ⌘⇧\\ |
| 专注模式 | ⌘⇧F |
